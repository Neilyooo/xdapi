企业分组与多渠道成本路由更新

  • 2026-05-30 11:08 CST 补充 New API / XDAPI 企业私有分组实施说明。
  • 同模型多渠道时，XDAPI 会按 group + model 找渠道；多渠道满足条件时先按 priority，同优先级按 weight。
  • 请求最终会记录具体 channel_id，因此可以做渠道审计和成本归因；但默认扣费不是按渠道成本自动变化，而是按模型价格和分组倍率计算。
  • 企业合同价建议使用私有 group、GroupRatio / GroupGroupRatio、专属 token、模型限制和可选专属渠道实现。
  • 详细图解见 企业分组与多渠道成本路由详解。
